LinkClean – Tracking aus Links entfernen

Browser-Erweiterung für Chrome und Edge: entfernt Tracking-Parameter wie utm_source, fbclid oder gclid aus Links – lokal im Browser.

Funktionen

  • Automatisch: 48 bekannte Tracking-Parameter werden beim Aufruf einer Seite entfernt, bevor sie lädt (über die in Chrome eingebaute Schnittstelle declarativeNetRequest).
  • Seitenspezifisch: zusätzliche Regeln für YouTube, Spotify, Amazon, TikTok, X/Twitter, Facebook, Reddit und eBay.
  • Sauberen Link kopieren: ein Klick kopiert die aktuelle Adresse ohne Tracking. Weiterleitungslinks von Google, Facebook, Instagram, YouTube, LinkedIn und Reddit werden dabei entpackt, sodass das echte Ziel geteilt wird.
  • Auf dieser Seite pausieren: schaltet die automatische Bereinigung für eine Website ab, falls sie ihre Parameter braucht. Anmeldeseiten von Google, Apple und Microsoft sowie Google Docs und Gmail sind standardmäßig ausgenommen.
  • Ein/Aus-Schalter, Zähler im Symbol für bereinigte Links im aktuellen Tab, hell/dunkel, Deutsch und Englisch.

Datenschutz

Kein Konto, keine Statistik, keine Server: Die Erweiterung sendet keine Daten. Datenschutzerklärung LinkClean

Installation in Chrome oder Edge (entpackte Erweiterung)

  1. ZIP herunterladen und in einen dauerhaften Ordner entpacken (z. B. Dokumente/LinkClean). Den Ordner danach nicht löschen – der Browser lädt die Erweiterung von dort.
  2. Erweiterungsseite öffnen: in Chrome chrome://extensions, in Edge edge://extensions.
  3. Entwicklermodus einschalten (Chrome: oben rechts, Edge: links).
  4. Entpackte Erweiterung laden (Edge: Entpackt laden) wählen und den entpackten Ordner auswählen, in dem die Datei manifest.json liegt.
  5. Optional über das Puzzle-Symbol in der Symbolleiste anheften.

Voraussetzung: Chrome bzw. Edge ab Version 110. Entpackt geladene Erweiterungen werden nicht automatisch aktualisiert; für eine neue Version den Ordner ersetzen und auf der Erweiterungsseite Neu laden klicken. Firefox wird derzeit nicht unterstützt.

Berechtigungen

  • declarativeNetRequestWithHostAccess und Zugriff auf alle Websites: Tracking-Parameter aus der Adresse entfernen, bevor die Seite lädt. Seiteninhalte werden nicht gelesen.
  • storage: Ein/Aus-Schalter, Liste pausierter Seiten und Zähler.
  • activeTab: Adresse des aktuellen Tabs zum Kopieren lesen, nur nach Klick.
  • clipboardWrite: sauberen Link in die Zwischenablage schreiben.

LinkClean – remove tracking from links

Browser extension for Chrome and Edge: removes tracking parameters such as utm_source, fbclid or gclid from links – locally in your browser.

Features

  • Automatic: 48 known tracking parameters are removed when a page is requested, before it loads (via Chrome’s built-in declarativeNetRequest API).
  • Site-specific: extra rules for YouTube, Spotify, Amazon, TikTok, X/Twitter, Facebook, Reddit and eBay.
  • Copy clean link: one click copies the current address without tracking. Redirect links from Google, Facebook, Instagram, YouTube, LinkedIn and Reddit are unwrapped so the real destination is shared.
  • Pause on this site: turns automatic cleaning off for a website that needs its parameters. Google, Apple and Microsoft sign-in pages as well as Google Docs and Gmail are skipped by default.
  • On/off switch, badge with the number of cleaned links in the current tab, light/dark, English and German.

Privacy

No account, no analytics, no servers: the extension sends no data. LinkClean privacy policy

Installing in Chrome or Edge (unpacked extension)

  1. Download the ZIP and extract it to a permanent folder (e.g. Documents/LinkClean). Do not delete the folder afterwards – the browser loads the extension from there.
  2. Open the extensions page: chrome://extensions in Chrome, edge://extensions in Edge.
  3. Turn on Developer mode (Chrome: top right, Edge: left side).
  4. Click Load unpacked and select the extracted folder that contains manifest.json.
  5. Optionally pin it via the puzzle icon in the toolbar.

Requires Chrome or Edge 110 or later. Unpacked extensions are not updated automatically; for a new version replace the folder and click Reload on the extensions page. Firefox is not supported at the moment.

Permissions

  • declarativeNetRequestWithHostAccess and access to all sites: remove tracking parameters from the address before the page loads. Page content is not read.
  • storage: on/off switch, list of paused sites and counter.
  • activeTab: read the current tab’s address for copying, only after a click.
  • clipboardWrite: write the clean link to the clipboard.
